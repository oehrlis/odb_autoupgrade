# OraDBA Autoupgrade Extension v0.5.0

**Release Date:** 2026-10-08

## Overview

Version 0.5.0 adds comprehensive proxy and truststore handling for corporate environments, complete configuration
examples for all three AutoUpgrade modes, and a helper script for network pre-flight checks.

## Highlights

- Full proxy support with environment variable precedence and credential stripping
- Truststore resolution from OS or explicit path
- Three complete configuration examples: download, create_home, goldimage
- Shared patch configuration via environment variable
- Pre-flight connectivity validation
- Documentation and BATS test suite

## Details

### Added

- **Wrapper and Library**
  - `bin/au_run.sh` - Wrapper with proxy/Java/truststore resolution
  - `lib/au_lib.sh` - Utility functions for environment handling

- **Configuration**
  - `etc/autoupgrade.env.example` - All environment variables documented
  - `etc/au_download.cfg` - download patches, optionally a gold image (`AU_GOLD_IMAGE=YES`)
  - `etc/au_create_home.cfg` - create a new home from the staged folder, no keystore
  - `etc/au_deploy.cfg` - out-of-place patching of one database
  - One patch list `AU_PATCH` for all modes (default `RECOMMENDED`, pin in `patches/au_patch.env`)

- **Helper Scripts**
  - `bin/au_check_connectivity.sh` - Network endpoint validation

- **Documentation**
  - `doc/proxy-and-truststore.md` - covering:
    - Proxy configuration and JVM properties
    - Truststore resolution and CA certificate setup
    - MOS keystore creation and auto-login modes
    - Gold image AUTO fall-back logic
    - Runtime data preservation
    - Network endpoint reference

- **Testing**
  - `tests/au_run.bats`, `tests/au_check_connectivity.bats` - BATS tests (wrapper, library, connectivity check)

### Changed

- Environment precedence: caller environment wins over config file
- Lowercase `https_proxy` export for Java compatibility
- Java version check now configurable

### Fixed

- Exit code handling under `set -euo pipefail`
- Config file validation (abort when not found)

## Upgrade Notes

Behaviour changes to check when replacing an existing installation in place:

- Scripts are renamed (`au_run.sh`, `au_update_jar.sh`, `au_keystore.sh`); the old names still work as
  deprecation shims. Copy `bin/` and `lib/au_lib.sh` together. `keystore/`, `patches/` and `logs/` stay
  untouched.
- Java resolution prefers `$ORACLE_HOME/jdk/bin/java` over `java` in `PATH`; set `AUTOUPGRADE_JAVA_HOME`
  to pin a JDK.
- A config that references an unset variable now aborts with the variable names instead of running with
  empty values.
- The OS truststore is used automatically when present; `AUTOUPGRADE_TRUSTSTORE=none` restores the JDK
  cacerts.
